# Жишиг: court decision analyzer

AI-powered analysis of Mongolian court decisions (source: shuukh.mn) for lawyers.

- **UI prototype:** open `prototype/index.html` in a browser. It is a single file with no build step. All data in it is fictional.
- **Product and system design:** [DESIGN.md](DESIGN.md)
